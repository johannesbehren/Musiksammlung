# Musiksammlung
Eine Ansammlung von Minecraft Musik und Mods

# Anwendung + Änderungen:

--Anzeige--
- Spielender Song wird im Webnamen angezeigt
- Links Playlists
- Mitte Songs von Playlist
- Unten Steurung

--Steuerung--
- Anzeige des zurzeit spielenden Songs (oder zuletzt gespielte Song)
- Start / Stop ist klar
- Vorher / Nächster ist klar
- Wiederholung:
  - Aus
  - Eins: Song wiederholt sich
  - Alle: Nach dem letzten Song beginnt es beim ersten in der selben Playlist
- Zufall: Einer der Songs in der selben Playlist random als nächsten
- Lautstärkeregler
  - Mit Maus +/- 5%
  - Mit Pfeiltasten +/- 1%
