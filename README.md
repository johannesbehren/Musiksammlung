# Musiksammlung
Eine Ansammlung von Minecraft Musik und Mods

# Anwendung + Änderungen:

--Anzeige--
- Spielender Song wird im Webnamen angezeigt
- Links Playlists
- Mitte Songs von Playlist
- Unten Steurung
  - Detail zu den gespielten / ausgewählten / nächstspielendes Song

--Steuerung--
- Anzeige des zurzeit spielenden Songs (oder zuletzt gespielte Song)
  - Beim Klick auf dem Namen des Songs, wird man zum derzeit spielenden Song navigiert
    1. Situation: Von einer Playlist zur anderen wechselnd und zum Song runter gehend, bis der Song als erstes oben ist
    2. Situation: Auf der selben Playlist, aber weggescrolled, dann wird man nach unten gehend, zum spielenden Song gebracht
- Start / Pause ist klar
- Vorher: Bringt zum vorhergespielten Song von den gespielten Songs, die mal gespielt oder ausgewählt waren
- Nächster: Spielt das nächste Song von der Liste ab oder das durch den Zufall gewählt wurde
- Wiederholung:
  - Aus
  - Eins: Song wiederholt sich
  - Alle: Nach dem letzten Song beginnt es beim ersten in der selben Playlist
- Zufall: Einer der Songs in der selben Playlist zufällig als nächsten
  - Bei jedem wiederholten Einschalten des Zufall Knopfes, wird ein anderes Song ausgewählt
- Lautstärkeregler
  - Mit Mausrad oben/runter +/- 5%
  - Mit Pfeiltasten oben;rechts/runter;links +/- 1%

--Theme--
- Knopf unter "Meine Sammlung"
  - Aktiviert / Deaktiviert den hohen Kontrast aller Farben
